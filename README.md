# Amazon Product Cart – React Application

## 📌 Project Overview

Amazon Product Cart is a React-based web application designed to demonstrate the core functionality of an online shopping cart. It provides a user-friendly interface for viewing products and managing selected items in a shopping cart.

The project focuses on understanding React components, state management, event handling, and modern frontend development practices.

## 🎯 Objectives

- Develop an interactive product shopping interface using React.
- Implement product selection and shopping cart functionality.
- Understand component-based architecture and state management.
- Create a clean, responsive, and user-friendly interface.

## ✨ Key Features

- **Product Display:** View available products and their details.
- **Add to Cart:** Add selected products to the shopping cart.
- **Cart Management:** Review and manage selected items.
- **Quantity Management:** Update product quantities, if implemented.
- **Price Calculation:** Display the cart total, if implemented.
- **Interactive UI:** Provide a smooth user experience through React components.

## 🛠️ Technologies Used

- **Frontend:** React.js
- **Programming Language:** JavaScript
- **Structure:** HTML5
- **Styling:** CSS3
- **Development Tool:** Vite, if configured in the project
- **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

### Prerequisites

- Node.js and npm installed on your system.
- A code editor such as Visual Studio Code.

### Steps to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Nashling123/Amazon-.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Amazon-
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal.

## 🧪 Testing

Test the application by checking:

- Whether products can be added to the cart.
- Whether cart contents update correctly.
